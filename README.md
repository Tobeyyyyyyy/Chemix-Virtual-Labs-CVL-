# Chemix Virtual Lab

An original, dependency-free browser prototype inspired by virtual chemistry-lab interaction patterns.

## Run
Open `index.html` directly in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload the three files: `index.html`, `styles.css`, `app.js`.
3. Go to **Settings → Pages**.
4. Set **Deploy from a branch**, choose `main` and `/root`.
5. Open the Pages URL.

## What is included
- Dark virtual-lab interface
- Equipment/chemical palette
- Drag-and-drop bench
- Selectable objects
- Inspector for properties
- Zoom controls
- Save to browser localStorage
- Experiment steps
- Basic simulated observation engine
- Responsive layout

## Next-level architecture
For a production version, replace the emoji/CSS apparatus with custom SVG or GLB assets, then add a physics/liquid engine and a structured experiment rules engine. Keep original branding, assets, and copy.
