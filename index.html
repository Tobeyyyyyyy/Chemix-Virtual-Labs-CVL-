Chemix Virtual Labs

A browser-based workspace for designing, simulating, and teaching chemistry experiments.

What it is

Chemix Virtual Labs lets teachers and students draw lab setups, run chemical simulations, and explore reactions — all in the browser. No installation, no plugins.

Features

  • Drag-and-drop apparatus library
  • Magnetic snap and merge
  • Live reaction effects
  • Snap-to-grid, zoom, and pan canvas
  • Light & dark themes, accent colours

Technology

HTML5 Canvas for the workspace, vanilla JavaScript for logic, and glassmorphism CSS for the interface. No frameworks, no build step.

Credits

Iconography and apparatus data inspired by the open chemistry education community. Built with respect for real lab safety practice.
